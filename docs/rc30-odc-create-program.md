# RC30 — Création du programme ODC

Un clic sur **Candidatures ODC** crée l’appel *Orange Digital Center — Appel à candidatures 2026* (`odc-appel-2026`) puis l’ouvre (`draft → open`).

Champs, critères (max 100 pts, seuil 60) et pièces (CIN, pitch deck) sont dans `apps/app-robia/src/lib/odc-default-program.ts`.

Pas de `robia.odc.decide` automatique. Décision humaine inchangée.
